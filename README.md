Swagata Recipe Finder | MERN Stack Web Application

Swagata Recipe Finder is a full-stack web application designed to help users easily discover, explore, and manage their favorite recipes. The application provides a user-friendly interface with secure authentication and personalized recipe management features.

Key Features:

User Authentication: Secure user registration and login using JWT-based authentication and password hashing.

Recipe Browsing: Explore a collection of recipes with detailed information.

Search Functionality: Search recipes by name or keywords.

Category Filtering: Filter recipes by Vegetarian and Non-Vegetarian categories.

Recipe Details: View complete recipe information, including descriptions, cooking time, ingredients, and step-by-step instructions.

Favorites Management: Add recipes to a personal favorites list and remove them whenever needed.
Protected Routes: Restrict access to personalized features for authenticated users.

Responsive UI: User-friendly and responsive interface for desktop and mobile devices.

Technologies Used: React.js, Node.js, Express.js, MongoDB, JavaScript, Tailwind CSS, Axios, JWT, and React Router.

Purpose: To provide a simple and convenient platform for discovering, searching, and organizing recipes in one place.
